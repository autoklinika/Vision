# Testy Vision

Etap inicjalizacji: testów aplikacji jeszcze nie ma.

W kolejnych PR wprowadzimy zestawy: mock urządzeń, stabilność metadanych, geometria, kontrola jakości, regresja obrazu oraz próby bezpiecznego zatrzymania ruchu. CI nie może wymagać podłączenia rzeczywistego aparatu ani manipulatora; testy sprzętowe będą osobną bramką z logami.
